Use the Import Wizard to make many entries at once from a `.csv` file. You can also type the entries in its table.

:::note
Only a **Books Manager** or a **System Manager** can import entries. The Import Wizard is not available on a phone.
:::

## Prepare the File

1. Click **Setup** > **Import Wizard** in the sidebar.
2. Select an **Import Type**, such as **Sales Invoice** or **Item**.
3. Click **Save template**. The browser downloads a `.csv` template file.
4. Open the file in a spreadsheet app, and enter the values below the header row.
5. Save the sheet as a `.csv` file.
6. Click **Select file**, and select the file.

The import types are **Sales Invoice**, **Purchase Invoice**, **Payment**, **Journal Entry**, **Party**, **Item**, **Tax Template**, **Account**, **Address**, and **Number Series**. When inventory is on, you can also import **Stock Movement**, **Shipment**, **Purchase Receipt**, and **Location**.

The Import Wizard makes new entries only. It does not change entries that exist.

A template column for a table field has the table name in brackets, such as `Item (Items)`. The Import Wizard also reads files from the **Export** button of a list view, and templates from the RareBooks desktop app.

## Check the Values

The rows of the file show in a table.

- To change a value, click its cell and edit it.
- To add a row, click **Add row**. You can use this to make entries without a file.
- To remove a row, click the **x** button in the **#** column.

If the Import Wizard cannot convert a value, the cell gets a red border. Move the pointer over the cell to see the error.

Each column has a field selector at the top. If your file does not use the template, select the field for each column. Select **None** to ignore a column. You cannot import while two columns have the same field (**Duplicate columns found**), or while a required field has no column (**Required fields not selected**).

To leave fields out of the template and the import, click the **…** button in the page header, and then click **Pick import columns**. You cannot clear a required field.

## Import the Data

1. Click **Import data**.
2. For entries that you can submit, such as invoices, the **Submit entries?** dialog opens. Click **Yes** to submit the entries, or **No** to keep them as drafts.
3. Wait for the import to complete.

If the **Cannot import** dialog opens, fix the cells or the links that it lists. Then click **Import data** again.

The **Import complete** dialog shows the number of imported entries, and each failed entry with its error:

- **Show me** opens the list of the new entries. This button shows only when no entry failed.
- **Done** clears the Import Wizard so that you can make more entries.
- **Fix failed** keeps only the failed rows. Fix them, and click **Import data** again.

## Import Entries with Child Tables

Some entries have a child table. For example, a sales invoice has an **Items** table with one row for each item that you sell. For these entries:

![Import Wizard with the Sales Invoice type and a CSV file loaded: six rows that make three invoices, grouped by the Invoice No values A, B, and C.](/images/docs/books-docs-import-wizard-1-rows-loaded-v4.png)

1. Put each table row on a different row of the file.
2. Give all the rows of one entry the same value in the name column, such as **Invoice No**.
3. Enter the other values of the entry, such as the customer, in the first row. You can also repeat them in each row.

:::caution
The Import Wizard ignores a row that has no value in the name column.
:::

For example:

| Invoice No | Customer | Item (Items) | Quantity (Items) |
| --- | --- | --- | --- |
| A | Lin | Bat | 1 |
| A | Lin | Ball | 3 |
| B | Andy | Pen | 10 |
| B | Andy | Pencil | 20 |
| B | Andy | Ink | 2 |

This file makes two sales invoices. Invoice **A** has two items, and invoice **B** has three items. The name column only groups the rows. RareBooks names each new entry from its [number series](/settings/number-series/), such as `SINV-1001`.
